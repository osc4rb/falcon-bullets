# Falcon Sans

`FalconSans-Regular.ttf` is a modified version of **Source Sans 3** by Adobe, licensed under the
SIL Open Font License 1.1 (see `OFL.md`). It is renamed because "Source" is a Reserved Font Name.

Changes (built by `tools/build_font.py` from `SourceSans3VF-Upright.ttf`):
- weight fixed at 415, chosen so filled text carries the same ink as the Myriad Pro entries on a
  real USAFA Form 715A rendered by Acrobat
- lowercase `l` / `ł` use the straight alternate (`l.a`), matching Myriad
- subset to Latin-1 plus common punctuation
